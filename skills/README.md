# Skills for Open News Monitor

This folder contains AI-maintenance skills that travel with the repository. They are not required for an ordinary user to run the monitor.

`news-source-research` is the source-onboarding standard: an AI maintainer uses it before adding a new RSS feed, API, or website source. The application itself must implement the relevant checks in code so that non-technical users do not need Codex to use the monitor.

When updating a skill, update the corresponding product documentation and tests if the source-onboarding behaviour changes.
