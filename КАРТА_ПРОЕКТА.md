# Карта проекта Open News Monitor

## Назначение

Open News Monitor — открытый self-hosted агент для мониторинга выбранных новостных источников. Он собирает новые публикации, применяет понятные правила отбора, исключает повторы и создаёт источник-связанный дайджест.

## Где что лежит

| Путь | Назначение |
| --- | --- |
| `src/open_news_monitor/` | Рабочий код агента |
| `examples/` | Безопасные шаблоны настроек |
| `tests/` | Автоматические проверки и RSS-фикстуры |
| `docs/` | Инструкции по запуску и подключению каналов |
| `skills/news-source-research/` | Методика проверки новых источников для поддерживающего ИИ |
| `AGENTS.md` | Обязательные правила работы ИИ внутри репозитория |
| `Материалы/` | Исходные материалы пользователя; не изменяются программой |
| `runtime/` | Локальная база и дайджесты запуска; не попадают в Git |

## Первый личный тест

Используйте `examples/ai-work-monitor.json` как отдельный профиль для мониторинга ИИ-инструментов и новостей. Сначала запускайте его с `--dry-run`; это не создаёт отправок в Telegram, email или Google Sheets.
