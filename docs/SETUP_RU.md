# Запуск Open News Monitor на Windows

## Что делает агент

Open News Monitor следит за выбранными вами публичными источниками новостей. Он сохраняет уже обработанные ссылки в локальной SQLite-базе и в следующих запусках показывает только новые публикации. По умолчанию результат остаётся на компьютере в Markdown-файле и отчёте о состоянии.

Сейчас проверены RSS/Atom, часть открытых JSON-источников, мастер создания профиля, первая инициализация памяти, защита от повторов и локальный статус. Telegram, email и Google Sheets есть в коде, но ещё не прошли сквозную проверку в публичной версии.

## 1. Установка

1. Установите Python 3.11 или новее.
2. Скачайте или клонируйте репозиторий.
3. Откройте PowerShell в папке репозитория.
4. Выполните:

```powershell
.\scripts\setup-windows.ps1
```

Скрипт создаёт локальное окружение Python и устанавливает проект. Он не создаёт профиль, не запускает мониторинг и не отправляет сообщения.

Если выполнение скрипта запрещено политикой PowerShell, выполните вручную:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .
```

## 2. Создание профиля

```powershell
.\scripts\create-monitor.ps1 -Name my-monitor
```

Профиль будет создан в `config/local/my-monitor.json`, который не попадает в Git. Мастер по очереди попросит название, URL и название источника, подтверждение подключения, правила отбора и способ доставки. Для первого безопасного запуска оставьте выбор доставки пустым: тогда агент создаст только локальную Markdown-подборку и SQLite-память.

### Что означает проверка источника

| Статус | Простое значение | Действие мастера |
| --- | --- | --- |
| `READY` | Найдены реальные публикации с заголовком, датой и ссылкой. | Предлагает добавить источник. |
| `NEEDS_SETUP` | Сайт доступен, но его нельзя надёжно подключить автоматически. | Не добавляет, предлагает другую ссылку. |
| `UNSUPPORTED` | Формат источника пока не поддерживается. | Не добавляет. |
| `ERROR` | Возникла временная техническая проблема. | Не добавляет и предлагает повторить позже. |

RSS/Atom и некоторые открытые JSON-источники могут подключиться автоматически. Если на обычном сайте объявлена RSS/Atom-лента, мастер покажет её адрес и будет собирать новости через неё.

Обычный HTML-сайт без готовой ленты пока не подключается автоматически. Ему нужна отдельная настройка и проверка заголовка, даты и прямой ссылки.

## 3. Первая инициализация памяти

После создания профиля мастер спросит:

```text
Запомнить текущие публикации как отправную точку? Да/Нет
```

Выберите `Да` или `yes`. Агент запишет текущие публикации в SQLite-базу, не отправляя их в Telegram, email или Google Sheets. Затем он покажет число обработанных источников и сохранённых публикаций. Если один источник недоступен, результат будет показан отдельно; профиль не считается полностью инициализированным.

Если выбрать `Нет`, первый обычный запуск может включить уже существующие публикации. Позже выполните безопасную инициализацию вручную:

```powershell
.\.venv\Scripts\python.exe -m open_news_monitor run config\local\my-monitor.json --initialize
```

Повторная инициализация не удаляет ранее сохранённую память.

### Примечание о PowerShell

При автоматической передаче ответов в PowerShell кириллица иногда искажается. Если «Да» не распознано, введите `yes`. В обычном интерактивном запуске также поддерживаются `Да`, `д` и `y`.

## 4. Обычный запуск и статус

```powershell
.\.venv\Scripts\python.exe -m open_news_monitor run config\local\my-monitor.json
.\.venv\Scripts\python.exe -m open_news_monitor status config\local\my-monitor.json
```

Обычный запуск собирает новые публикации, исключает уже известные ссылки и обновляет локальный Markdown-дайджест и файл статуса. Команда `status` показывает время последнего запуска, результат каждого источника и ошибки.

Для безопасного просмотра без записи в память и без доставки:

```powershell
.\.venv\Scripts\python.exe -m open_news_monitor run config\local\my-monitor.json --dry-run
```

## 5. Проверить ссылку отдельно

```powershell
.\.venv\Scripts\python.exe -m open_news_monitor probe-source https://example.org/news --name "Мой источник"
```

Проверка не создаёт профиль и не отправляет сообщения. Для уже известной RSS/Atom-ленты есть команда `check-source`.

## 6. Локальные данные и секреты

Не добавляйте в Git `.env` и `.env.*`, `config/local/`, SQLite-базы, `runtime/`, токены Telegram, ID чатов, SMTP-пароли и ключи Google. `.gitignore` уже исключает эти файлы.

## Пока не реализовано или не подтверждено

- графический интерфейс;
- встроенное автоматическое расписание;
- автоматический анализ произвольных HTML-сайтов;
- сквозная проверка Telegram, email и Google Sheets в публичной версии.
