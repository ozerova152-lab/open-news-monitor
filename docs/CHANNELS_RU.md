# Подключение каналов доставки

Эта инструкция нужна после создания профиля. Секреты хранятся только на вашем компьютере в `.env` в папке Open News Monitor. Не отправляйте токены, пароли приложений или JSON-ключи AI-помощнику в чат и не добавляйте их в Git.

После настройки выполните локальную проверку:

```powershell
.\.venv\Scripts\python.exe -m open_news_monitor doctor config\local\my-monitor.json
```

`ГОТОВО` означает, что программа видит нужные локальные данные. Команда не входит в сервис, не отправляет сообщения и не доказывает, что внешняя доставка уже работает.

## Telegram

Подготовьте созданного Telegram-бота, его токен из BotFather и ID отдельного тестового чата, куда бот может писать. В локальном `.env` сохраните:

```text
ONM_TELEGRAM_BOT_TOKEN=ваш_токен
ONM_TELEGRAM_CHAT_ID=ваш_ID_чата
```

AI-помощник может объяснить, где получить данные, но не должен просить вставлять их в чат. После `doctor` пользователь отдельно разрешает одну тестовую отправку в согласованный тестовый чат. Помощник проверяет статус `SENT` и не повторяет отправку без нового разрешения.

## Gmail через SMTP

Подготовьте Gmail-адрес, включённую двухэтапную аутентификацию, пароль приложения Google и отдельный тестовый адрес получателя. В `.env` сохраните:

```text
ONM_SMTP_HOST=smtp.gmail.com
ONM_SMTP_PORT=587
ONM_SMTP_USERNAME=ваш_Gmail
ONM_SMTP_PASSWORD=пароль_приложения
ONM_SMTP_FROM=ваш_Gmail
```

Адрес получателя мастер запрашивает при выборе email. `doctor` проверит заполнение, но не будет входить в Gmail. Для первого теста пользователь отдельно разрешает одно письмо на согласованный тестовый адрес; AI-помощник использует тестовые публикации и не повторяет письмо без нового разрешения.

## Google Sheets

Подготовьте отдельную тестовую Google-таблицу и лист, проект Google Cloud с включённым Google Sheets API, сервисный аккаунт, JSON-ключ и редакторский доступ сервисного аккаунта к таблице.

Установите дополнительную поддержку:

```powershell
.\.venv\Scripts\python.exe -m pip install -e ".[sheets]"
```

Сохраните JSON-ключ вне отслеживаемых Git файлов, например в `config\local\`. В `.env` укажите только путь:

```text
ONM_GOOGLE_SERVICE_ACCOUNT_FILE=C:\путь\к\ключу.json
```

В мастере профиля выберите Google Sheets, укажите ID или ссылку тестовой таблицы и название листа. `doctor` проверит библиотеки, наличие файла и базовую структуру ключа, не показывая его содержимое. Для первого теста пользователь отдельно разрешает запись только трёх публикаций `TEST ONLY` в отдельную таблицу. После подтверждения AI-помощник проверяет `SENT` и не выполняет повторную запись без разрешения.

## Общие ограничения

Telegram, Gmail и Google Sheets прошли контролируемые реальные тесты. Это не даёт абсолютной гарантии: если внешний сервис принял сообщение или строку, но ответ потерялся, повторная попытка может создать внешний дубль. Локальные очереди сохраняют неполучившие подтверждение публикации и не обрабатывают подтверждённые `SENT` повторно.
