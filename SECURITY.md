# Security policy

## Reporting a vulnerability

Please do not open a public issue for a potential security vulnerability or exposed secret.

Use GitHub private security advisory reporting for this repository when it is available. If private reporting is not available, contact the maintainer through the contact links on the GitHub profile and include:

- a concise description of the issue;
- affected version or commit, if known;
- safe reproduction steps; and
- potential impact.

We will acknowledge a good-faith report and work with you on a responsible disclosure.
